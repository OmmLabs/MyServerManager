Server App Manager runs on your PC and connects to one Ubuntu server over its existing SSH service.

- Start with the [Windows quickstart](./quickstart.md).
- Check [compatibility and permissions](./compatibility.md) for your setup.
- Use [applications](./applications.md), [metrics](./metrics.md), [logs](./logs.md) and [website health](./website-health.md) for everyday operations.
- Read the [security model](/security/) before sharing logs or enabling privileged operations.

The current channel is a source preview.
