Server App Manager brings Ubuntu application status, logs and website checks into a dashboard on your PC. The source preview gives developers a way to try the local setup and review how it works.

<!-- truncate -->

Start with the [Windows quickstart](/docs/quickstart/). You will verify a server fingerprint, sign in with your existing SSH account and review a service before adding it to the dashboard.

The project blog will cover practical tasks such as finding your ASP.NET Core service, reading its journal, checking cgroup memory and diagnosing Nginx errors. The [compatibility page](/docs/compatibility/) explains the preview's prerequisites. [Community](/community/) explains how to share a reproducible issue.
