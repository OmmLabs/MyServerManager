# About Server App Manager

Server App Manager gives developers and small teams one place to see and operate the apps they already run on Ubuntu. The dashboard stays on the operator's PC and uses SSH to work with the server's existing system tools.

The project is sponsored by Omm Rudraksha. Read the [project guides](/docs/) and [contribution information](/community/). [Omm Rudraksha](https://ommrudraksha.com/).
