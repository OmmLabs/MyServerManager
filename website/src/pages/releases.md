# Release notes

## 0.1.0-preview.1 source preview

- The dashboard and solution use the Server App Manager name.
- The local SSH flow supports verified host fingerprints, password sign-in, approved application discovery and service controls.
- The dashboard shows Linux metrics, journal entries and public website health. Nginx and SQL Server actions require the appropriate configuration and permissions.
- The public site has setup guides, a blog and a local search index.

See the [compatibility table](/docs/compatibility/) for preview limits and [download](/download/) for the matching setup steps.
