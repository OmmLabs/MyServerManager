# From your PC to your first service

<figure className="demo-shot">
  <img src="/img/setup-preview.png" width="1040" height="650" alt="Server App Manager setup form with an SSH address field and Continue button." />
  <figcaption>The first setup screen on a Windows PC. The example address is a placeholder.</figcaption>
</figure>

1. **Start locally.** Open the dashboard in your browser on the same PC as the app.
2. **Verify the Ubuntu host.** Enter the SSH address you use and check the fingerprint before entering a password.
3. **Review an application.** Find a candidate, confirm its systemd unit and add it to the list.
4. **Inspect before acting.** Open status and recent logs. When a change is needed, review the action and check its actual result.

Use the [quickstart](/docs/quickstart/) to try this flow with a disposable test server. See the [feature guide](/features/) for the other dashboard pages.
