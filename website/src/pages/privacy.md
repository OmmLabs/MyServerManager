# Privacy

The project site serves public pages and a local search index. Search terms are processed in the browser. The site includes no project analytics script or credential form. Links to GitHub and Omm Rudraksha lead to those services.

The local dashboard keeps its server registration, app list and audit history on your PC. It uses your SSH credentials to connect to the server you select. Website health checks connect from your PC to the configured public URL. See the [security guide](/security/) and [local data instructions](/docs/update-and-remove/).
