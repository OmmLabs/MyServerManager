# What you can manage

| Area | What you can do |
| --- | --- |
| [Applications](/docs/applications/) | Find existing .NET services, approve app entries and start, stop or restart the units you manage. |
| [Metrics](/docs/metrics/) | See service memory, PID and CPU time beside Ubuntu CPU, RAM and disk. |
| [Logs](/docs/logs/) | Search and filter recent systemd journal entries for a registered app. |
| [Website health](/docs/website-health/) | Check a public URL from your PC and see its HTTP status and response time. |
| [Nginx](/docs/nginx/) | See status and validate configuration before an approved reload or restart. |
| [SQL Server](/docs/sql-server/) | Check the service and explicitly confirm a permitted restart. |
| [Audit History](/security/) | Review actions and their actual outcomes locally. |

[See the setup demo](/demo/) or [start with the Windows quickstart](/docs/quickstart/).
